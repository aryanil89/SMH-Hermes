# mcp-tools

MCP servers (TypeScript, via the [MCP TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk))
that give Hermes Agent structured access to live infrastructure data:

- storage capacity and risk state
- CI/CD pipeline health
- code dependency graphs
- infrastructure topology (see [../uno-q](../uno-q) for the one tool backed by real hardware)

**Not yet implemented** — Day 2 scope per [../docs/REQUIREMENTS.md](../docs/REQUIREMENTS.md).
