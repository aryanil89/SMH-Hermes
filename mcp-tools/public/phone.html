    Enrol someone

    Disabled for this demo: a hand-typed name here has no real embedding behind it -- posting one from a phone at the rack is a live demo risk, not a credential. Adding a name would not use a badge, QR code, or face scan either way -- it would just add that name to the roster so the decision log can refer to it. The only physical-security signal is the rack's distance sensor detecting presence; every access decision is made by a human reviewing the captured photo.
